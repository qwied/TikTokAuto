StreamClipper — Политика конфиденциальности

Действует с 23 ноября 2026 года

1. О проекте

StreamClipper — личный инструмент автоматизации: он нарезает интересные моменты из трансляций и публикует готовые вертикальные клипы в TikTok-аккаунт владельца через официальный TikTok Content Posting API. Сервис работает только для учётной записи владельца проекта и не принимает загрузки от третьих лиц.

2. Какие данные обрабатываются

  • идентификатор TikTok-аккаунта (open_id), полученный через OAuth Login Kit при явном разрешении владельца аккаунта;
  • токены доступа (access token и refresh token), необходимые для публикации;
  • видеофайлы клипов, создаваемые самим инструментом из публичных трансляций;
  • технические журналы работы (статусы публикаций, ошибки).

3. Как данные используются

Данные используются исключительно для одной цели: публиковать клипы в TikTok-аккаунт владельца и поддерживать работу автоматизации (обновление токена, статусы загрузок). Мы не продаём данные, не передаём их третьим лицам, не показываем рекламу и не собираем статистику посещений.

4. Хранение и защита

Токены хранятся в защищённом хранилище секретов GitHub (Encrypted secrets) и никогда не публикуются. Видеофайлы хранятся в закрытом выпуске (Releases) репозитория владельца. Доступ к секретам имеет только владелец.

5. Отзыв доступа

Вы можете в любой момент отозвать доступ приложения к TikTok-аккаунту: TikTok → Профиль → Настройки и конфиденциальность → Безопасность → Управление доступом приложений → отозвать StreamClipper. После отзыва токены перестают действовать и удаляются из хранилища секретов.

6. Данные третьих сторон

Инструмент взаимодействует с API платформ трансляций (Twitch, YouTube) для определения выходящих в эфир каналов и с API TikTok для публикации. Обработка подчиняется политикам соответствующих платформ.
