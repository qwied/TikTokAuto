SC StreamClipper

Клипы появятся здесь

Как только чат стримера «взорвётся», готовый вертикальный клип (35–60 с по силе момента, субтитры, RubUP в середине) появится здесь автоматически.

Подключить компьютер

  1. Запустите run.bat на компьютере — окно программы покажет адрес
  2. Введите адрес сюда и нажмите «Войти»
  3. Готово — клипы будут прилетать сами

На iPhone: Поделиться → «На экран „Домой“» — сайт станет приложением и будет открываться даже без интернета.

Эта страница открыта по https и не может достучаться до http-адреса. Откройте адрес сервера в Safari напрямую или поднимите https-туннель (cloudflared — инструкция в README проекта).

Настройки

Адрес показывается в окне программы на компьютере («Веб-интерфейс: http://…:8765»). Если эта страница открыта прямо с компьютера — адрес уже подставлен.

GitHub Pages работает по https и не может обращаться к серверу по http. Откройте адрес сервера в Safari напрямую или поднимите бесплатный https-туннель cloudflared (инструкция в README, раздел «GitHub Pages»).

Кнопка «TikTok» сохранит токен (Content Posting API — как получить, написано в README). Клип готов → сам уходит в TikTok: 35–60 секунд, субтитры внизу, баннер RubUP в середине, хештеги #fyp #рек #стрим.

GitHub без компьютера (автоматизация)

Нужен только для кнопки «Каналы» с телефона — добавляет ссылку стримера в subscriptions.json вашего репозитория. Создать токен за минуту: github.com → Settings → Developer settings → Fine-grained personal access tokens → Generate → выберите только свой репозиторий → Repository permissions → Contents: Read and write. TikTok подключается через Secrets репозитория (README, «Откуда брать данные»).

Пуши на устройство (прям с сайта, без приложений)

iPhone: сначала добавьте сайт на экран «Домой» (Safari → Поделиться → «На экран „Домой“»), затем откройте с иконки и нажмите кнопку — iOS спросит разрешение. Уведомления будут приходить от иконки StreamClipper. Подписка хранится в репозитории (push_subscriptions.json).

Как это работает
  1. run.bat на ПК — программа сама следит за каналами из links.txt
  2. Чат «взорвался» — вертикальный клип 35–60 с с субтитрами готов
  3. Уведомление прилетает на любое устройство (Telegram / ntfy / Bark)
  4. «Скачать» — видео уходит на телефон и прячется в «Загруженное»

Каналы

Киньте ссылку ОДИН раз — следим постоянно и максимально быстро: стример вышел в эфир → запись включилась сама → клипы снимаются сами. Можно и ссылку на видео YouTube / клип Twitch — нарежем вертикальные клипы с субтитрами. А ещё бот САМ находит топовые эфиры Twitch по зрителям и следит за ними (ваши каналы всегда важнее).

Качество клипов (субтитры и интересные моменты)

Под каждого клипа на карточке есть кнопки Интересно / Скучно: «Скучно» делает отбор канала строже, «Интересно» — свободнее. На карточках клипов из видео есть кнопка Ещё отсюда — заказ следующей минуты.

Синхронизация с GitHub

Канал добавлен, настройки изменены, поставили оценки «Интересно/Скучно»? Нажмите кнопку — получите КОД со всем этим, скопируйте и пришлите его в чат Z.ai: всё попадёт в монитор за минуту.

Реклама RubAp / RubUp

Пока на стриме идёт реклама, нарезка СТОП (на карточке канала кнопка РЕКЛАМА). Реклама кончилась — тапните ещё раз, нарезка продолжится. Серверная реклама ловится и ставится на паузу автоматически.
