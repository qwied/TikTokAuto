SC StreamClipper В ленту

Нарезка по твоим ссылкам

Вставь сколько хочешь ссылок YouTube — хоть 1000, по одной в строке (можно вместе с текстом, бот вытащит ссылки сам). Каждый ролик скачается и порежется на вертикальные шортсы 9:16 с субтитрами и баннером. Уже нарезанные зачеркнутся — повторно они не режутся. Режим «Всё подряд» режет весь ролик подряд, без отбора моментов.

Как это работает

Порядок
1. Ссылки уходят в очередь репозитория пакетами по 50 шт.
2. Через минуту стартует нарезка: скачивание → 9:16 → субтитры → баннер.
3. Клип за клипом появляются в ленте и постятся в TikTok.
4. Ссылки, которые бот уже нарезал, зачеркнутся в списке сами — статусы обновляются каждые 20 секунд.
5. Длинный ролик нарезается цепочкой запусков (по ~40 клипов за заход); очередь из 1000 ссылок разгребается часами — просто не закрывай вкладку,
статусы видно всегда.

Пока приложение TikTok на модерации, посты идут «только для меня» — после одобрения новые клипы станут публичными автоматически.
GitHub-токен (если нарезка не отправляется)

Токен нужен, чтобы сайт мог положить твой запрос в репозиторий. Хранится только в твоём браузере (localStorage). Создать: github.com → Settings → Developer settings → Fine-grained tokens → Generate → выбрать свой репозиторий → Repository permissions → Contents: Read and write.
